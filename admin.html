How to use this page
  1. Enter your song title, date, and Philippine release time.
  2. Create a fine-grained GitHub token with access only to rmlv31/rmLv and repository Contents read/write permission.
  3. Paste the token and press Publish Release.
  4. Wait for GitHub Pages to update, then check Discography. The countdown is visible to everyone.
  5. The access-token field is automatically cleared when a publish or delete operation finishes. Paste it again for your next action. The token is never saved by this page.
