Release Manager 🦋

Add a new countdown without replacing existing ones, or manage countdowns and published songs.

Security: this page is not secret. Anyone can open it, but only someone with a valid GitHub token for this repository can publish. Use a fine-grained token limited to this repo with Contents: Read and write. The token is used only in this page's memory and is not saved.

Create a fine-grained token in GitHub Settings → Developer settings → Personal access tokens. Choose only repository rmlv31/rmLv, grant Contents: Read and write, and set an expiration. Never share this token with anyone.

How to use this page
  1. Enter your song title, date, and Philippine release time.
  2. Create a fine-grained GitHub token with access only to rmlv31/rmLv and repository Contents read/write permission.
  3. Paste the token and press Publish Release.
  4. Wait for GitHub Pages to update, then check Discography. The countdown is visible to everyone.
  5. Clear the token field and close the page when finished. The token is never saved by this page.

Publishing appends to upcoming.json so existing countdowns remain. Removing published songs edits releases.json. Neither action publishes music to streaming platforms.
